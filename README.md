# AI-FITNESS-ROUTINE-GENERATOR
**B.Tech CSE (AI) - 1st Year Capstone Project**

### 📌 Project Overview
An interactive web application built with **Python**, **Streamlit**, and the **Google Gemini API** that generates personalized weekly workout routines based on a user's age, weight, height, fitness goal, available days, and equipment.

### 🛠️ Tech Stack
- **Language:** Python 3.x
- **Frontend UI:** Streamlit
- **Data Handling:** Pandas (CSV Filtering)
- **AI Model:** Google Gemini API (`gemini-2.5-flash` - Free Tier)
